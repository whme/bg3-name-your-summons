Multi-summons left unnamed by the "Do not name them" mode no longer stay
suppressed after you change the mode. Detecting such a group used to record a
skip-this-session mark, so switching to "Share one name" or "Name each
individually" never re-prompted a summon type already cast this session. The
group is now simply skipped for that cast without recording anything, so the
next cast is re-evaluated under whatever mode is set then. Explicit skips of a
single summon are untouched and still survive a mode change.
