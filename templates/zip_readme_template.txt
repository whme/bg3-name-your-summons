Name Your Summons - v{{VERSION}}


REQUIREMENTS

- Baldur's Gate 3 Script Extender (BG3SE), API v30 or newer:
  https://github.com/Norbyte/bg3se/releases


INSTALLING

1. This archive contains a single mod file:
     {{PAKNAME}}
   Move it into:
     %LOCALAPPDATA%\Larian Studios\Baldur's Gate 3\Mods\
2. Launch the game and enable "Name Your Summons" from the Mods menu.


UPDATING FROM 1.2.0 OR EARLIER

Delete the old versioned pak (for example NameYourSummons-1.2.0.pak) from your
Mods folder before adding this one. The .pak now has a stable filename, so
future updates overwrite it in place - but an old versioned file left behind
would make the game load the stale copy.


ABOUT

Names your summoned creatures, remembers the names, and reapplies them
automatically the next time you summon the same creature.

Project page, screenshots, and support:
https://github.com/whme/bg3-name-your-summons
